## 🚀 Projetos em Destaque

### ☀️ 1. SolarClean
> **Aplicação Web para Monitoramento Pós-Venda Fotovoltaico**
- **Descrição:** Plataforma focada em ajudar empresas integradoras de energia solar no acompanhamento contínuo das usinas de seus clientes. Conta com cálculo de desempenho, estimativa de prejuízo por baixa geração e sistema de alertas de falhas/limpezas.
- **Destaques:** Gestão por perfis de acesso (Admin e Cliente), planejamento completo de regras de negócio, contratos de API e arquitetura de dados.

### ⚡ 2. Painel Executivo — Portfólio de Geração
> **Plataforma Analytic ETL & Visualização de Dados da ANEEL**
- **Descrição:** Sistema de extração (ETL), tratamento e visualização de dados públicos de outorgas de geração de energia elétrica no Brasil (solar e eólica) com base nos dados do SIGA/ANEEL.
- **Destaques:** Pipeline com motor de matching por similaridade (RapidFuzz) e curadoria humana (Human-in-the-loop), suporte a autenticação JWT, gráficos interativos e mapas georreferenciados.
- **Tecnologias:** Python (FastAPI), Pandas, RapidFuzz, PostgreSQL, SQLAlchemy, Alembic, React (Vite), Tailwind CSS e ECharts.

### 🍱 3. DevDelivery
> **Sistema Web de Delivery e Gestão para Restaurantes**
- **Descrição:** Aplicação completa para montagem de pedidos pelo cliente final e gerenciamento operacional em tempo real pelo restaurante (cardápio, status de pedidos, relatórios e fechamento de caixa).
- **Destaques:** Autenticação JWT com controle de acesso baseado em papéis (RBAC), estrutura modular, migrações com Alembic e testes automatizados rodando em banco PostgreSQL isolado por transações.
- **Tecnologias:** FastAPI, PostgreSQL, SQLAlchemy, React 19, Tailwind CSS v4, React Hook Form e Recharts.
